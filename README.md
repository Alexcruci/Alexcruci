# 🚀 Projects

## 🔹 Project Zero — Job Market Data Pipeline

An end-to-end Data Engineering project built around real job-market data.

The pipeline collects job postings from multiple external APIs, stores the original responses as raw data, transforms and validates the records with Python, and loads the resulting dataset into PostgreSQL.

### What I built

- REST API data extraction
- Pagination and retry handling
- Raw JSON data storage
- Data cleaning and normalization
- Duplicate detection and removal
- Detection and filtering of anomalous records
- Relational PostgreSQL database
- Many-to-many relationships between jobs and skills
- SQL analysis
- Power BI reporting layer

### Data model

The PostgreSQL database contains entities such as:

- Jobs
- Companies
- Locations
- Skills
- Job–Skill relationships

The project currently processes **more than 13,000 job postings** and tens of thousands of job-skill relationships.

**Stack:**  
`Python` · `Pandas` · `REST APIs` · `JSON` · `PostgreSQL` · `SQL` · `Power BI`

> The goal of the project is not only to analyse job-market data, but to build the complete pipeline that makes that analysis possible.
